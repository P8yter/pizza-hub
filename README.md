# Social Tap

Pagina hub mobile per un'attività, pensata come destinazione di un tag NFC.

## Prima della pubblicazione

1. In `index.html`, sostituisci le iniziali con un logo, quindi aggiungi indirizzo, telefono, link al menu e numero WhatsApp della pizzeria. I due pulsanti segnalati come da aggiungere sono temporanei.
2. Pubblica la cartella su un hosting (GitHub Pages, Netlify, Vercel oppure il tuo hosting web).
3. Crea un link Bitly che punta all'URL pubblicato, ad esempio `bit.ly/nome-attivita`.
4. Scrivi **il link Bitly** nel tag NFC. In seguito potrai cambiare la destinazione da Bitly senza riprogrammare il tag.

Il codice è statico: non richiede database né costi di server applicativo.
